# 两次通信：编码与定位

## 题目描述

这是一道 **run-twice（两次运行）通讯题**，形式参考 Codeforces 2168A2 与 2168B。

你的程序会在同一组数据上运行两次。第一次运行结束后，程序占用的内存会全部丢失；第一次运行输出的小写字符串会作为第二次运行的输入传回给你。

### 第一次运行：编码

输入格式：

```text
first
n
p1 p2 ... pn
```

其中 $n$ 是排列长度，$p$ 是 $1$ 到 $n$ 的一个排列。

你需要输出一个小写英文字符串 $s$（$1 \le |s| \le 10^5$），作为传递给第二次运行的信息。

### 第二次运行：定位

输入格式：

```text
second
s
```

其中 $s$ 就是第一次运行输出的字符串。第二次运行不会再次给出排列 $p$。

你需要输出一个整数 $P$，表示整数 $n$ 在排列 $p$ 中的位置（下标从 $1$ 开始）。

## 数据范围

- $1 \le n \le 10^4$
- $p$ 是 $1,2,\ldots,n$ 的一个排列
- 第一次输出的编码串只能包含小写英文字母 `a` 到 `z`，长度不超过 $10^5$

## 样例

第一次运行输入：

```text
first
3
3 2 1
```

第一次运行输出（一种合法编码）：

```text
aaaa
```

第二次运行输入：

```text
second
aaaa
```

第二次运行输出：

```text
1
```

解释：排列为 $[3,2,1]$，整数 $3$ 在位置 $1$。样例中的程序把位置减一后按 26 进制编码成 4 个字符，因此位置 $1$ 被编码为 `aaaa`。

## 提示

- 两次运行之间不能共享变量，第一次运行的输出字符串是唯一的信息通道。
- 本题只需要定位整数 $n$，不需要还原整个排列；但任何合法编码方案都可以使用。
- 注意：本平台的通讯题机制不会在第二次运行中提供交互查询，所有信息都必须由第一次运行的输出携带。
