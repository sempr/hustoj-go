# 奇偶子集的双射（通讯题）

## 题目描述

给定 `n`（`1 ≤ n ≤ 50`）和升序互异的整数集合  
`S = { a_1、a_2、…、a_k } ⊆ {1, 2, …, n}`。

这是一道**通讯题**：Setter 在第一轮给你集合 `S`，你的程序需要把第一轮输出的
集合 `T` 作为第二轮的输入，再次输出集合，最终得到的集合必须与第一轮得到的
`S` 一致；也就是说，两轮的运算互为逆映射，构成 {1..n} 的子集间的一个
**双射**，且 `|T| mod 2 ≠ |S| mod 2`（奇偶性改变）。

具体来说：

- **第一轮输入**：`n`、`k` 和 `S` 的元素；输出任意除 `k` 奇偶性不同外无额外要求的
  升序子集 `T`； Setter 会把你的第一轮输出作为第二轮输入。
- **第二轮输入**：`n`、`|T|` 和 `T` 的元素；输出一个升序子集，这个子集必须正好是
  第一轮输入中的 `S`。

 Setter 保证第一轮的 `S` 是互异且升序；你输出的集合也必须是互异且升序。

 Setter 限制：程序的两次运行**不能共享内存**——所有状态必须从 stdin 读入，输出作为下一轮的输入。

## 输入格式

**第一轮**

第一行两个整数 `n`、`k`；第二行 `k` 个互异且升序的整数 `a_i`（`1 ≤ a_i ≤ n`）。

**第二轮**

Setter 会把你第一轮的输出作为本论的输入，格式与第一轮一致（第一行 `n`, `|T|`；
第二行 `T` 的元素）。

## 输出格式

**第一轮 / 第二轮** 均输出两行：

- 第一行：`n` 和 `l`（`0 ≤ l ≤ n`，`l` 的奇偶性与本轮输入 `k` 不同）；
- 第二行：`l` 个升序的互异整数。

多空格、多换行无害。

## 样例

**第一轮输入**

```text
5 3
1 3 5
```

**第一轮输出（合法）**

```text
5 2
1 3
```

**Setter 把此输出作为第二轮输入**

```text
5 2
1 3
```

**第二轮输出（期望）**

```text
5 3
1 3 5
```

## 提示

把 `n` 从集合里 toggling 即可：在集合含 `n` 时删除它，不含时追加它。
这样两次 toggle 恢复原状。
