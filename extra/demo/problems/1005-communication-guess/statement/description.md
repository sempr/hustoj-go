# 多轮猜数（通讯题）

## 题目描述

这是一道**通讯题**。你的程序会被评测程序运行多次，每次只处理当前这一轮。

每一轮开始时，标准输入会给出两个整数 `L R`，表示隐藏整数 `x` 当前所在的闭区间（`L ≤ x ≤ R`）。你需要输出一个整数 `guess`，表示你这一轮的猜测，并且必须满足 `L ≤ guess ≤ R`。

### 猜错时，下一轮的区间如何确定？

评测程序已经知道隐藏整数 `x`。如果你的猜测不是 `x`，它会比较 `guess` 和 `x` 的大小，并只保留**仍然可能包含 `x`** 的那一部分区间：

| 本轮情况 | 说明 | 下一轮输入 |
|---|---|---|
| `guess < x` | 答案在猜测的右侧 | `guess+1 R` |
| `guess > x` | 答案在猜测的左侧 | `L guess-1` |
| `guess == x` | 猜中 | 没有下一轮，本题通过 |

也就是说，下一轮的区间是把本轮区间去掉 `guess` 后，包含 `x` 的那一半。区间不是随机变化的，完全由你的猜测和答案的大小关系决定。

如果猜中了 `x`，评测立即结束，本题通过，不会再给出下一轮输入。

### 注意

- 你的程序每一轮都会被重新启动，不能依赖上一轮的变量或内存；
- 每轮只能输出一个整数，不能在一轮内进行多次猜测；
- 如果输出的数不在当前区间 `[L, R]` 内，直接判为错误；
- 本题最多运行 100 轮。

## 输入格式

每一轮的标准输入只有一行，包含两个整数 `L` 和 `R`：

- 第一轮的 `L R` 由测试数据给出；
- 之后每一轮的 `L R` 由评测程序按照上面的规则自动生成。

数据范围：`1 ≤ L ≤ R ≤ 10^9`。

## 输出格式

输出一个整数 `guess`，表示本轮的猜测。

- 必须满足 `L ≤ guess ≤ R`；
- 输出后立即结束本次运行。

## 样例

第一轮输入：

```text
1 100
```

一种合法输出：

```text
50
```

假设隐藏整数是 `x = 73`，因为 `50 < 73`，所以下一轮输入会变成：

```text
51 100
```

如果这一轮再猜 `75`，因为 `75 > 73`，下一轮的输入就会变成：

```text
51 74
```

## 提示

每次猜当前区间的中点，可以把区间长度至少缩小一半。区间长度为 `R-L+1` 时，最多约 `ceil(log2(R-L+1))` 轮即可猜中，远小于 100 轮。
