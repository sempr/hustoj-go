# 猜数字

## 题目描述

这是一道**交互题**。

评测程序会先告诉你轮数 $t$，然后依次进行 $t$ 轮。每一轮都有一个隐藏的整数 $x$（$1 \le x \le 10^6$），你需要通过不断提问把它猜出来。

每一轮中，你可以多次输出一个整数 $g$ 作为你的猜测。评测程序会对每次猜测给出一个回应：

- `-1`：你猜的数**偏小**了（$g < x$）；
- `0`：你猜**对**了（$g = x$）；
- `1`：你猜的数**偏大**了（$g > x$）。

当你收到 `0` 后，本轮结束，进入下一轮。**每一轮最多只能猜 20 次**；如果某一轮猜了 20 次仍未猜中，则判定为**答案错误（WA）**。

只有在 $t$ 轮全部猜中的情况下，你的程序才会被判为**通过（AC）**。

## 交互格式

**每次输出都必须换行并刷新缓冲区**（`C++` 用 `std::endl` 或 `std::cout.flush()`，`Python` 用 `print(..., flush=True)`），否则会发生死锁。

1. 读取一个整数 $t$，表示轮数。
2. 对每一轮：
   - 输出一个整数 $g$（$1 \le g \le 10^6$）作为一次猜测；
   - 读取一个整数 $r$，即评测程序对本次猜测的回应（`-1` / `0` / `1`）。

## 数据规模

- $1 \le t \le 10$
- 隐藏数字与每次猜测均满足 $1 \le x, g \le 10^6$
- 每一轮最多猜测 20 次

## 交互示例

下面是一次可能的交互过程（评测数据中 $t = 2$，两轮的隐藏数字分别为 $5$ 与 $123$）：

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| 评测 → 程序 | `2` | 共 2 轮 |
| 程序 → 评测 | `500` | 第 1 轮：猜 500 |
| 评测 → 程序 | `1` | 偏大 |
| 程序 → 评测 | `100` | 第 1 轮：猜 100 |
| 评测 → 程序 | `1` | 偏大 |
| 程序 → 评测 | `5` | 第 1 轮：猜 5 |
| 评测 → 程序 | `0` | 猜中，进入第 2 轮 |
| 程序 → 评测 | `123` | 第 2 轮：猜 123 |
| 评测 → 程序 | `0` | 猜中，全部结束 |

## 提示

$2^{20} = 1048576 > 10^6$，因此每轮的 20 次猜测刚好够用二分查找。
